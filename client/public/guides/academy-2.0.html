1. C’est quoi Academy ?

Cobblemon Academy 2.0 est un modpack Fabric centré sur Cobblemon : tu captures, combats, explores un overworld massivement custom, et tu progresses via gyms, quêtes, cartes, et une vraie économie serveur.

Ce n’est pas du Cobblemon « vanilla » : le pack ajoute des centaines de structures, AllTheMons (légendaires / mythiques / UB / paradoxes), Mega Showdown, Legendary Monuments, UI étendue, et des systèmes Academy (boosters, lootbags, encens shiny, fossils OP, etc.).

1000+ créaturesBase Cobblemon + AllTheMons R4.0. Les rares sont calibrés ≈ 1 / 10 000+.
Monde transforméWilliam Wythers + Oh The Biomes We’ve Gone + Regions Unexplored. End = Stellarity.
Overworld pacifiquePeu de hostiles sauvages. Le danger est surtout dans structures, raids, monuments.
Progression RPGGyms / badges, quêtes EasyNPC, cartes à collectionner, économie CD + arcade.

2. Premiers pas (J1–J3)

Checklist d’arrivée

  1. Fabrique / achète des Poké Balls et pars explorer le biome de spawn.
  2. Ouvre le Cobbledex et le Pokefinder : vois ce qui peut spawn ici.
  3. Active toute Waystone trouvée (téléport plus tard).
  4. Équipe un backpack — les structures lootent beaucoup.
  5. Parle aux PNJ Academy / EasyNPC (lettres, quêtes, tutoriel).
  6. Ne panique pas si tu ne vois aucun légendaire : c’est voulu (voir section spawns).

Boucle de jeu typique

Explorer biomes → remplir le dex → loot structures → farm arcade / CobbleDollars → shops → améliorer équipe → gyms → chasse ciblée des rares (météo / Y / biome).

3. Monde & exploration

Biomes

  • Overworld très varié (3 overhauls combinés).
  • Chaque biome a ses pools Cobblemon — utilise le Pokefinder.
  • Nether / End custom (Stellarity côté End).

Structures

  • Centaines de structures (YUNG, Trek, ATI, Moog’s, villages, etc.).
  • Loot mixte vanilla + Cobblemon.
  • Gyms / hideouts / raids = contenu « dangereux ».

5. Lootbags — ce que ça drop

À l’ouverture (clic droit), chaque lootbag exécute une commande définie dans config/academy/item_logic.json (ou défaut du jar Academy).

LootbagTirageContenu
lootbag_mythsandlegends 1 item · table academy:gimmicks/legendaries ~65 objets Legendary Monuments + Mega Showdown (ailes, flûtes, clés, tablets Regi, treats chiens, orbes Dialga/Palkia/Giratina, cube Zygarde, épée/bouclier rouillés…). Poids 1 ou 2 (ailes / treats / lightstone un peu plus fréquents).
lootbag_megastone 1 stone · table academy:gimmicks/megastones 46 Méga-Pierres Mega Showdown à poids égal (~2,17 % chacune) : Vénusarite → Tyranitarite, Charizardite X/Y, Mewtwonite X/Y, etc.
lootbag_gymkey 1 clé · table academy:radgyms/keys Clé Rad Gyms d’un des 18 types (normal… fairy), équiprobable (~5,56 % chacun).
lootbag_plushie 3 dolls · table academy:pokeblocks/basic_bundle Poids par rareté : common 64 · uncommon 40 · rare 16 · epic 4 · legendary 1 (sur ~125). Pools : 15 / 14 / 18 / 15 / 14 pokedolls pokeblocks:.
lootbag_shinyplushie 1 doll shiny · table academy:pokeblocks/shiny 70 pokedolls shiny équiprobables (Absol, starters, légendaires shiny, paniers Applin, etc.).
lootbag_hats /lootables random … lootables:hats Pool Lootables « hats » (chapeaux / vanity). Sur cette instance le fichier de pool n’est pas présent — le bag appelle quand même cette ID.
lootbag_academybiomeblend /lootables random … lootables:biomeblendsacademy Pool Lootables « biomeblendsacademy » (mélangeurs de biome). Idem : ID référencée, pool non packagée ici.
Les lootbags se vendent surtout via le shop Minigames (catégorie Academy Premium), pas via un CobbleMerchant « academy ».

6. Machines Gacha (Basic / Great / Ultra / Master)

Listes pokemons / items vides + usePokemonList: false / useItemList: false → le mod tire des Pokémon du spawn pool monde Cobblemon (pas une liste custom), classés par bucket de rareté de spawn. Aucun item en récompense gacha actuellement.

MachineMise (min–max)Probas de raretéCe que tu peux drop
Basic50 – 9999common 100 %Uniquement des espèces common du spawn pool
Great250 – 9999common 70 % · uncommon 30 %Common + uncommon
Ultra1000 – 9999common 45 % · uncommon 35 % · rare 20 %Jusqu’aux rares de spawn
Master4500 – 9999common 35 % · uncommon 30 % · rare 25 % · ultra-rare 10 %Seule machine avec bucket ultra-rare (légendaires ATM inclus si dans le pool)
  • Shiny ≈ 0,012 % par tir · aspect (forme) ≈ 5 % (toutes machines).
  • Le pool exact = toutes les espèces présentes dans le WORLD_SPAWN_POOL Cobblemon (donc AllTheMons inclus), filtrées par le bucket tiré.
  • Pour lister précisément « quels mons » : ce sont ceux qui spawnent en jeu dans chaque bucket, pas un catalogue YAML séparé.

7. Économie (serveur)

Deux circuits qui se complètent :

CobbleDollars Monnaie principale monde. Dépensée chez les CobbleMerchant (plusieurs PNJ spécialisés). Gains : loot, playtime, quêtes, ventes éventuelles selon configs serveur.
Coins Arcade (Minigames) Gagnées sur les machines (snake, flappy, blockstacker, roulette, slots, pinball, gacha…). Dépensées dans le shop Minigames (miroirs + extras : starters, ores en packs, Academy premium).
Calibration actuelle : ≈ 15k coins arcade / 15 min en jeu sérieux. Blockstacker : 800 / 3k / 10k (rangées 6–8). Snake/Flappy multiplier ×4. Roulette mises 250 / 1k / 2.5k. Entrée machines très basse (coinToPlay ≈ 1) — le sink est le shop, pas le ticket d’entrée.

Arcade — ce qui est configurable

  • Snake / Flappy : coinToPlay, multiplier
  • Blockstacker : prix par rangée + vitesse
  • Roulette : tailles de mises par table
  • Gacha : min/max wager + raretés
  • Pinball / slots / derby : surtout enabled (+ coinToPlay pinball/slots).
  • Blackjack : uniquement blackjack.enabled (true/false). Pas de mise, payout, ratio, ou table configurable dans config.yml — règles/payouts hardcodés dans le mod.

10. Taux de spawn des rares (AllTheMons R4.0)

Comme dans l’Excel d’ajustement :

  1. Cobblemon tire d’abord un bucket (ultra-rare beaucoup plus rare que rare).
  2. Ensuite un mon est choisi selon les weights dans le pool local (mêmes conditions).
  3. Le tableau « ≈ 1 sur N » approxime la rareté globale face à la concurrence hors-ATM.

Cible serveur ≈ 1 spawn rare / 10 000+ rencontres. Arceus ≈ 1 / 20 000 (volontairement plus dur). Chien légendaires / Arceus ont été buff vs versions trop rares.

Le « % pool local » du fichier MD n’est pas ta chance à chaque pas. Pour chasser, suis biome + heure + météo + hauteur Y, puis regarde le « 1 sur ».
